## Problem Statement

`backend/app/services/market_overview_builder.py::_dimension_rank(rows, repo, kind, limit=5, level=None) -> dict`
是市场看板(Market Overview,`/` 路由主页)的核心聚合函数:对 `rows: list[dict]`
的 ~5000+ 个 A 股 + ETF + 指数,按 `kind` 维度(industry / sector / concept 之一)聚合,
产出 leading / lagging top-N(默认 5)。`build_market_overview` orchestrator 调它 19 次
(7 个 industry + 多个 sector + concept,each with optional level)。

调用方 (per 2026-10-19 grep):

- `app/api/overview.py:359` `market_overview(request, as_of)` — Dashboard 路由,每次页面加载
- `app/services/market_overview_builder._build_overview` 间接 — daily pipeline 跑批

`_dimension_rank` 当前 4 层 nested Python loop (line 254-308, 62 行):

1. `quote_map: dict[symbol, dict]` 从 `rows` 建(per-symbol dedup)
2. `groups: dict[group_name, dict[symbol, quote]]` 从 ext parquet + yaml 通过
   `ExtConfigStore(repo.store.data_dir)` 读(IO)
3. `items: list[dict]` per-group emit,aggregate change_pct / amount / leader
4. sort + slice → leading/lagging

3 个 helpers:
- `_top_rows(rows, key, descending, limit)` — 纯 compute filter + sort + project,15 行
- `_pct_band_rows(values)` — bucket 8 个涨跌幅 band,24 行

实测体感:Dashboard 每页加载调用 19 次(7 industry × ~5 sectors × 1 concept × 2 levels),
单次 ~5ms Python ref,总 ~95ms spike。算上其他 helper 在 orchestrator 里的累加,
Dashboard 首屏常因"市场看板"那块卡片延迟可见。

跟 Path A-1/2 的 indicator-level 函数不同:
- 输入不是 `polars.DataFrame`,是 service 对象 (`repo`) + 多个数据源
- 包含 filesystem IO (`ExtConfigStore.load_all()` + `_read_ext_rows()` 读 parquet/yml)
- 输出是 dict of list of dict,比 indicator 级更复杂

需要新 seam contract (per ADR-0006 §"5 段"):Python adapter 拥有 IO + cache,Rust kernel
只算 pure-compute on pre-aggregated inputs。

## Solution

迁 `_dimension_rank` + 2 helpers (`_top_rows` + `_pct_band_rows`) 到 Rust。
沿用 PyO3 + `pyo3-polars` 栈,新写 3 个独立 kernel(`top_rows_kernel` / `pct_band_rows_kernel`
/ `dimension_rank_kernel`),adapter 5 段 seam per ADR-0006:

1. **Pre-aggregate**:adapter 调 `ExtConfigStore.load_all()` + `_read_ext_rows()` (Python),
   建 `groups: list[(group_name, list[stock_fields])]` 中间态
2. **Rust kernel 多参数**:
   - `top_rows_kernel(rows, key, descending, limit) -> DataFrame`
   - `pct_band_rows_kernel(values) -> DataFrame`
   - `dimension_rank_kernel(groups, kind, level) -> DataFrame`
4. **Rust kernel 返回 DataFrame**:adapter `df.iter_rows(named=True)` 转 `list[dict]`
5. **Cache 由 Python 维护**:任何 `_cache` / `_cache_ts` 检查在 adapter 内,kernel 不感知

Path A-1 / 0002 (indicator-level) 的双轨测试 + try-import fallback + `_py_*` ref
命名约定全部 reuse,只有 fixture 形式从 240-day parquet 扩到 frozen `data_dir` 子集
(parquet + yaml + ext subset)。

## Implementation Decisions

### Service-level seam contract (per ADR-0006 §"5 段")

详见 ADR-0006 的 5 段定义。本 spec 仅补充本目标的 specific 决策:

1. **Pre-aggregate input shape to `dimension_rank_kernel`**:
   ```rust
   pub struct StockFields {
       pub symbol: String,
       pub name: Option<String>,
       pub change_pct: Option<f64>,
       pub amount: Option<f64>,
   }
   #[pyfunction]
   pub fn dimension_rank_kernel(
       groups: Vec<(String, Vec<StockFields>)>,
       limit: u32,
   ) -> PyResult<PyDataFrame>
   ```
   `groups` 是 `(group_name, list[stock_fields])` 数组,每 stock_fields 含计算 leader / change_pct
   aggregate 所需的最小字段。Adapter 负责从 `_read_ext_rows` 读 parquet → 构造 StockFields list。
2. **`top_rows_kernel` signature**:
   ```rust
   #[pyfunction]
   pub fn top_rows_kernel(
       rows: Vec<HashMap<String, PyObject>>,
       key: String,
       descending: bool,
       limit: u32,
   ) -> PyResult<PyDataFrame>
   ```
   `rows` 是 list of dict (Python adapter 把 `rows: list[dict]` 直传),
   `key` 是 sort 的列名 (`change_pct` / `amount` / `turnover_rate`),
   `descending` 是 bool,`limit` 是返回的 top N。
3. **`pct_band_rows_kernel` signature**:
   ```rust
   #[pyfunction]
   pub fn pct_band_rows_kernel(values: Vec<f64>) -> PyResult<PyDataFrame>
   ```
   8-bucket 涨跌幅分桶,固定 buckets: `<-5% / -5~-3% / -3~-1% / -1~0% / 0~1% / 1~3% / 3~5% / >5%`。

### Rust kernel 输出 shape (3 个 function 都是 DataFrame)

| Kernel | Output DataFrame columns | rows |
|---|---|---|
| `dimension_rank_kernel` | `name: String, count: u32, avg_pct: f64, up_count: u32, down_count: u32, amount: f64, source_field: Option<String>, leader_symbol: String, leader_name: Option<String>, leader_change_pct: Option<f64>` | 1 per group |
| `top_rows_kernel` | `symbol: String, name: Option<String>, close: Option<f64>, change_pct: Option<f64>, amount: Option<f64>, turnover_rate: Option<f64>, board: String` | top N |
| `pct_band_rows_kernel` | `label: String, count: u32, pct: f64` | 8 |

Adapter 端统一 `df.iter_rows(named=True)` 转 list[dict];对 `dimension_rank`,
再按 `avg_pct` 排序 + slice 拼 `{"leading": [...], "lagging": [...]}`。

### Algorithm (Rust) — 3 个 kernel

**`top_rows_kernel`**:

```rust
let mut filtered: Vec<&HashMap<...>> = rows.iter()
    .filter(|r| get_finite(&r, &key).is_some())
    .collect();
filtered.sort_by(|a, b| {
    let va = get_finite(a, &key).unwrap_or(0.0);
    let vb = get_finite(b, &key).unwrap_or(0.0);
    vb.partial_cmp(&va).unwrap_or(Ordering::Equal)  // descending default
});
// project to dict + slice to limit → return DataFrame
```

**`pct_band_rows_kernel`**:

```rust
let bands = [
    ("<-5%",   None,    Some(-0.05)),
    ("-5~-3%", Some(-0.05), Some(-0.03)),
    // ... 8 buckets
];
let total = (values.len() as f64).max(1.0);
let mut out_rows = vec![];
for (label, low, high) in bands {
    let count = values.iter().filter(|v| {
        match (low, high) {
            (None,    Some(h)) => **v < *h,
            (Some(l), None)    => **v >= *l,
            (Some(l), Some(h)) => **v >= *l && **v < *h,
            _ => false,
        }
    }).count();
    out_rows.push((label, count as u32, count as f64 / total * 100.0));
}
```

**`dimension_rank_kernel`** (per-group reduce):

```rust
for (group_name, stocks) in groups {
    let changes: Vec<f64> = stocks.iter()
        .filter_map(|s| s.change_pct)
        .collect();
    if changes.is_empty() { continue; }
    let count = stocks.len() as u32;
    let avg_pct = changes.iter().sum::<f64>() / changes.len() as f64;
    let up_count = changes.iter().filter(|v| **v > 0.0).count() as u32;
    let down_count = changes.iter().filter(|v| **v < 0.0).count() as u32;
    let amount: f64 = stocks.iter().filter_map(|s| s.amount).sum();
    let leader = stocks.iter()
        .max_by(|a, b| {
            // sort key 跟 Python `_leader_sort_key` 1:1
            let ka = leader_sort_key(a);
            let kb = leader_sort_key(b);
            kb.partial_cmp(&ka).unwrap_or(Ordering::Equal)
        });
    out_rows.push((group_name, count, avg_pct, up_count, down_count, amount, ...));
}
// 不在 kernel 里 sort:返回 DataFrame,adapter 端按 avg_pct 排 + slice
```

### Python wrapper (thin adapter)

```python
# backend/app/services/market_overview_builder.py

def _top_rows(rows, key, descending, limit):
    """thin adapter — try-import tf_rs_indicators.top_rows_kernel → fallback to _py_top_rows."""
    try:
        from tf_rs_indicators import top_rows_kernel
    except ImportError:
        return _py_top_rows(rows, key, descending, limit)
    out_df = top_rows_kernel(rows, key, descending, limit)
    return list(out_df.iter_rows(named=True))


def _pct_band_rows(values):
    try:
        from tf_rs_indicators import pct_band_rows_kernel
    except ImportError:
        return _py_pct_band_rows(values)
    out_df = pct_band_rows_kernel(values)
    return list(out_df.iter_rows(named=True))


def _dimension_rank(rows, repo, kind, limit=5, level=None):
    if not rows:
        return {"leading": [], "lagging": []}
    try:
        from tf_rs_indicators import dimension_rank_kernel
    except ImportError:
        return _py_dimension_rank(rows, repo, kind, limit, level)

    # Pre-aggregate (per ADR-0006 §1)
    quote_map = _build_quote_map(rows)
    groups: list[tuple[str, list[dict]]] = []
    store = ExtConfigStore(repo.store.data_dir)
    for config in store.load_all():
        field = _dimension_field(config, kind)
        if not field:
            continue
        for ext_row in _read_ext_rows(repo.store.data_dir, config, field):
            quote = _resolve_quote(ext_row, config, quote_map)
            if not quote:
                continue
            for value in _dimension_values(ext_row.get(field)):
                if level is not None and "-" in value:
                    value = _apply_level(value, level)
                groups.append((value, [quote]))
    # Adapter 给 kernel 的 input: list[(group_name, list[StockFields])]
    grouped = _regroup_for_kernel(groups)

    out_df = dimension_rank_kernel(grouped, limit)
    items = list(out_df.iter_rows(named=True))
    leading = sorted(items, key=lambda x: x["avg_pct"], reverse=True)[:limit]
    lagging = sorted(items, key=lambda x: x["avg_pct"])[:limit]
    return {"leading": leading, "lagging": lagging}
```

## Testing Decisions

- **What makes a good test for this spec**: bit-identical output of the kernel and the Python
  reference on a frozen `data_dir` (parquet + yaml + ext subset). The fixture is committed
  under `backend/tests/fixtures/market_overview_dim_240d/`. Parity fails → kernel drifted.
- **Modules under test**:
  - `crates/indicators/src/services_market_overview/{top_rows,pct_band_rows,dimension_rank}.rs`
    (Rust unit tests)
  - `backend/app/services/market_overview_builder.py::{_top_rows,_pct_band_rows,_dimension_rank}`
    (Python adapter, integration)
- **Prior art**: `crates/indicators/src/extreme_levels.rs::tests` (Path A-2, 3 unit tests);
  `backend/tests/test_rs_levels_seam.py` + `test_rs_extreme_levels_seam.py` (Path A-1/2 seam pattern)
- **How fixture is built** (one-time, then frozen):
  1. Capture current Python `_py_dimension_rank` + 2 helpers output on frozen 240-day
     data_dir (parquet + yaml + ext subset)
  2. Save the fixture dir + expected JSON outputs alongside
  3. Both Python reference + Rust kernel run against fixture; test compares outputs
  4. Failing test → kernel drifted (do **NOT** update expected output)
